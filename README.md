# Goutham — Portfolio

A static portfolio site built with HTML and CSS. It presents 10 software projects, plus a separate AI Commerce & Creative Studio showcase with its live demo, source repository, and campaign case study. Nine software projects link to public repositories; the featured Analytics Platform is identified as a local project whose repository is not yet published.

## Open locally

Open `index.html` in a browser. No build step, package install, or backend is required.

## Project links

The portfolio links to public repositories on [GitHub](https://github.com/gouthammmm). The AI Commerce & Creative Studio showcase links to its [live demo](https://ai-commerce-creative-studio.onrender.com/#shopify), [source repository](https://github.com/gouthammmm/ai-commerce-creative-studio), and [VELORA campaign case study](https://ai-commerce-creative-studio.onrender.com/static/case-studies/velora.html). The featured Analytics Platform is available locally, but its repository is not yet published. The standalone Natural Language to SQL app remains a local prototype and is intentionally omitted from the selected software project list.

## Files

- `index.html` — page content, project cards, and creative showcases
- `styles.css` — responsive layout and visual styling

The portfolio includes local AI Commerce screenshots and an optimized VELORA campaign image (`assets/velora-campaign-still.jpg`) so they are served directly by GitHub Pages. The VELORA image was generated with Adobe Firefly for a fictional independent project. Shopify Admin API access in the live demo requires server credentials; checkout there is simulated. Aftertide is a separate fictional visual-design concept.
