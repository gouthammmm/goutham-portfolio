# Goutham — Portfolio

A static portfolio site built with HTML and CSS. It presents 11 projects: ten include links to public GitHub repositories or live demos, and the featured Analytics Platform is identified as a local project whose repository is not yet published.

## Open locally

Open `index.html` in a browser. No build step, package install, or backend is required.

## Project links

The portfolio links to public repositories on [GitHub](https://github.com/gouthammmm), including the AI Commerce & Creative Studio demo. The featured Analytics Platform is available locally, but its repository is not yet published. The standalone Natural Language to SQL app remains a local prototype and is intentionally omitted from the selected project list.

## Files

- `index.html` — page content and project cards
- `styles.css` — responsive layout and visual styling

The portfolio includes a local VELORA campaign image at `assets/velora-campaign-still.png` so the project thumbnail is served by GitHub Pages. This image was generated with Adobe Firefly for a fictional independent project. Shopify Admin API access in the live demo requires server credentials; checkout there is simulated.
