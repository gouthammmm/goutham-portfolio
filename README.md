# Goutham — Portfolio

A static portfolio site built with HTML and CSS. It presents 10 projects: nine link to public GitHub repositories, and the featured Analytics Platform is identified as a local project whose repository is not yet published.

## Open locally

Open `index.html` in a browser. No build step, package install, or backend is required.

## Project links

The portfolio links to nine public repositories on [GitHub](https://github.com/gouthammmm), including Emotion Detection. The featured Analytics Platform is available locally, but its repository is not yet published. The standalone Natural Language to SQL app remains a local prototype and is intentionally omitted from the selected project list.

## Files

- `index.html` — page content and project cards
- `styles.css` — responsive layout and visual styling
